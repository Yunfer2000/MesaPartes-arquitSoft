# Requisitos funcionales

| ID | Requisito funcional |
|---|---|
| RF01 | El sistema deberá permitir el registro e inicio de sesión de usuarios. |
| RF02 | El sistema deberá permitir gestionar diferentes roles de usuario. |
| RF03 | El sistema deberá permitir registrar solicitudes de trámite documentario. |
| RF04 | El sistema deberá permitir seleccionar el tipo de trámite. |
| RF05 | El sistema deberá permitir adjuntar documentos digitales a una solicitud. |
| RF06 | El sistema deberá validar los datos obligatorios antes de enviar una solicitud. |
| RF07 | El sistema deberá generar automáticamente un código único de expediente. |
| RF08 | El sistema deberá registrar la fecha y hora de recepción de cada expediente. |
| RF09 | El sistema deberá permitir consultar el estado de un trámite. |
| RF10 | El sistema deberá permitir derivar expedientes hacia las diferentes áreas del instituto. |
| RF11 | El sistema deberá permitir asignar expedientes a responsables. |
| RF12 | El sistema deberá permitir observar o rechazar documentos indicando el motivo. |
| RF13 | El sistema deberá permitir subsanar documentos observados. |
| RF14 | El sistema deberá permitir cambiar el estado de los expedientes. |
| RF15 | El sistema deberá registrar el historial de acciones realizadas sobre cada expediente. |
| RF16 | El sistema deberá enviar notificaciones sobre cambios en el estado del trámite. |
| RF17 | El sistema deberá permitir generar documentos de respuesta. |
| RF18 | El sistema deberá permitir descargar documentos asociados al expediente. |
| RF19 | El sistema deberá permitir realizar búsquedas y filtros de expedientes. |
| RF20 | El sistema deberá generar reportes de trámites y expedientes. |
| RF21 | El administrador deberá poder gestionar usuarios, roles y permisos. |
| RF22 | El sistema deberá permitir consultar estadísticas de atención documentaria. |
| RF23 | El sistema deberá mantener la trazabilidad completa de cada expediente. |
| RF24 | El sistema deberá permitir al usuario consultar sus solicitudes anteriores. |
