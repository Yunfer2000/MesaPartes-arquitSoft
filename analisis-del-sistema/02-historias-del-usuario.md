# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como usuario externo, quiero registrarme e iniciar sesión, para acceder de manera segura al sistema. |
| HU02 | Como usuario externo, quiero registrar una solicitud de trámite documentario, para iniciar un trámite ante el instituto. |
| HU03 | Como usuario externo, quiero seleccionar el tipo de trámite, para indicar correctamente el procedimiento que deseo realizar. |
| HU04 | Como usuario externo, quiero adjuntar documentos digitales a mi solicitud, para presentar los requisitos correspondientes. |
| HU05 | Como usuario externo, quiero consultar el estado de mi trámite, para conocer el avance de mi solicitud. |
| HU06 | Como usuario externo, quiero subsanar documentos observados, para corregir las observaciones realizadas a mi solicitud. |
| HU07 | Como Mesa de Partes, quiero recibir y verificar las solicitudes, para validar la documentación presentada. |
| HU08 | Como Mesa de Partes, quiero generar un expediente con un código único, para identificar y realizar el seguimiento del trámite. |
| HU09 | Como Mesa de Partes, quiero derivar expedientes a las áreas correspondientes, para que sean atendidos por los responsables. |
| HU10 | Como Responsable de Área, quiero recibir y atender expedientes derivados, para gestionar las solicitudes correspondientes a mi área. |
| HU11 | Como Responsable de Área, quiero observar documentos indicando el motivo, para solicitar al usuario la corrección de información incompleta o incorrecta. |
| HU12 | Como Jefe de Área, quiero supervisar y validar la atención de los expedientes, para controlar el cumplimiento del proceso. |
| HU13 | Como Administrador, quiero gestionar usuarios, roles y permisos, para controlar el acceso a las funcionalidades del sistema. |
| HU14 | Como Administrador, quiero gestionar tipos de trámite y áreas, para mantener configurada la información institucional. |
| HU15 | Como Director, quiero consultar expedientes y reportes, para conocer el estado de la gestión documentaria. |
| HU16 | Como usuario externo, quiero recibir notificaciones sobre cambios en mi trámite, para conocer oportunamente su estado. |
| HU17 | Como usuario externo, quiero consultar mis solicitudes anteriores, para revisar el historial de mis trámites. |
