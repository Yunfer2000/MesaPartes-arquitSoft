# Historias de usuario

Cada historia corresponde a un caso de uso del análisis ICONIX del proyecto (CU02 a CU19; el CU01 "Registrar cuenta" se eliminó porque el público presenta sin cuenta).

| ID | Historia de usuario | CU |
|---|---|---|
| HU02 | Como personal del instituto, quiero iniciar sesión en una dirección aparte (subdominio), para trabajar sin que el login quede a la vista del público. | CU02 |
| HU03 | Como Administrador, quiero gestionar usuarios y roles, para controlar quién puede hacer cada operación. | CU03 |
| HU04 | Como Administrador, quiero gestionar las áreas del organigrama y de quién depende cada una, para derivar a la oficina correcta. | CU04 |
| HU05 | Como administrado, quiero presentar mi trámite sin crear una cuenta, con mis datos, el asunto y un PDF o ZIP, para no tener que ir al instituto. | CU05 |
| HU06 | Como administrado, quiero subsanar una observación desde la consulta pública, para corregir mi trámite sin empezar de nuevo. | CU06 |
| HU07 | Como administrado, quiero consultar mi trámite con mi N.° de expediente (o código propio) y mi DNI, para ver en qué área está. | CU07 |
| HU08 | Como Mesa de Partes, quiero recepcionar el expediente completando tipo, folios y N.° de documento, para dejar constancia de la fecha de recepción. | CU08 |
| HU09 | Como Mesa de Partes, quiero observar un expediente indicando el motivo, para que el administrado lo corrija. | CU09 |
| HU10 | Como Mesa de Partes o área, quiero derivar el expediente a un área destino y enviar copias para conocimiento, para que lo atienda quien corresponde. | CU10 |
| HU11 | Como Responsable de área, quiero confirmar que recibí el expediente, para que el plazo empiece a contar en mi área. | CU11 |
| HU12 | Como Responsable de área, quiero registrar avances, para que el administrado vea que su trámite se está atendiendo. | CU12 |
| HU13 | Como Responsable de área, quiero registrar la respuesta con su documento, para finalizar el trámite. | CU13 |
| HU14 | Como personal, quiero buscar expedientes por número, código, DNI, fecha, área o estado, para ubicar uno rápidamente. | CU14 |
| HU15 | Como Mesa de Partes, Administrador o Dirección, quiero generar reportes (PDF y CSV), para medir la gestión documentaria. | CU15 |
| HU16 | Como administrado, quiero recibir correos cuando mi trámite se presenta, se recibe, se observa, se deriva o se responde, para enterarme a tiempo. | CU16 |
| HU17 | Como Mesa de Partes, quiero registrar un documento que llegó en físico, con escaneo opcional y el código del sello, para que siga el mismo flujo que uno virtual. | CU17 |
| HU18 | Como Dirección General, quiero ver un semáforo de plazos y la lista de pendientes por área, para detectar expedientes olvidados. | CU18 |
| HU19 | Como cualquier persona, quiero verificar con un código o un QR que una constancia o respuesta es auténtica y que el archivo no fue modificado. | CU19 |
